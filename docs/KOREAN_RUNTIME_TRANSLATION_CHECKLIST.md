# Korean runtime translation checklist

Use this checklist during manual play testing. Record every English string that appears while `KOREAN` is selected.

- [ ] Launcher and main menu
- [ ] New Game and initial game options
- [ ] Save / load / confirmation dialogs
- [ ] IMP: male character creation
- [ ] IMP: female character creation
- [ ] A.I.M. home, sort, profile, hire, policies, history, alumni
- [ ] M.E.R.C. home, account, profiles, hire
- [ ] Bobby Ray front page, categories, item details, order form, shipments
- [ ] Insurance and florist
- [ ] Laptop email and files
- [ ] Strategic map labels, assignments, militia, helicopter, mines
- [ ] Tactical HUD, inventory, combat messages, interaction prompts
- [ ] Recruitable rebel dialogue
- [ ] Standard NPC dialogue
- [ ] A.I.M./M.E.R.C. mercenary spoken dialogue
- [ ] Help screens
- [ ] Credits / end-game paths

For each untranslated occurrence, capture:

1. screenshot;
2. exact English text;
3. screen/path where it appeared;
4. whether it is UI text, EDT dialogue, BinaryData text, or unknown.

Do not patch an untranslated runtime string directly until its owning resource is identified.
